# Contributing

Thanks for contributing to awesome-world-models!

## Adding an entry

- Search existing entries to avoid duplicates.
- Use the format: `- [Title](URL) - Short description ending with a period.`
- Keep descriptions to one sentence.
- Place the entry in the most relevant section; maintain alphabetical order within a section.
- Prefer primary sources (paper/project page) over mirrors.

## Pull requests

- One logical change per PR.
- Run a link check locally if possible.
- Update the table of contents if you add a new section.

## Scope

Entries should relate to world models: learned environment simulators for prediction, planning, and decision-making (video, 3D, driving, robotics, interactive). Off-topic submissions may be declined.
