# Roadmap

This roadmap tracks delivery of the `awesome-world-models` curated list. Work is organized into milestones; see the [Milestones](https://github.com/rajasekharponakala/awesome-world-models/milestones) and [Issues](https://github.com/rajasekharponakala/awesome-world-models/issues) for live status.

## v0.1 — Foundation

Repo scaffolding, README skeleton, LICENSE, CONTRIBUTING, structure definition, hygiene files.

## v0.2 — Core Curation

Foundational and recent (2024-2026) papers, implementations, datasets, benchmarks, tutorials.

## v0.3 — Automation & Quality

Link checker, awesome-lint, markdown formatting, status badges.

## v0.4 — Community

Issue/PR templates, Code of Conduct, governance doc.

## v1.0 — Public Launch

Final review, v1.0.0 release, announcement, submission to awesome lists index.
